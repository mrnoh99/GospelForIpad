# Lectionary — 전례력·미사 복음 독서 데이터 명세

`GospelForIpad/Lectionary.swift` 와 `GospelForIpad/LiturgicalCalendar.swift` 는 이 앱의
**1급 데이터**입니다. 「오늘의 복음」 카드가 보여 주는 모든 것(전례일 이름, 복음 장·절 범위,
재생 시작 위치)이 이 두 파일에서 나옵니다. 수정할 때는 반드시 이 문서의 검증 절차를 따르세요.

## 1. 구성

| 파일 | 역할 |
|------|------|
| `LiturgicalCalendar.swift` | 부활절(Meeus 알고리즘)·대림 시작·전례 시기/주차·주일 주기(가나다해)·평일 주기(홀짝수해)·한국 천주교 전례일 이름 |
| `Lectionary.swift` | 날짜 → 미사 복음 독서 `(복음서, 장, 시작절, 끝절)`. 대축일·축일 고유복음(`properReading`)이 시기 배열보다 우선 |
| `LectionaryValidator.swift` | DEBUG 빌드 실행 시 가·나·다해 3년 전 날짜를 순회하며 범위 검증 |
| `scripts/validate_lectionary.py` | 오프라인 검증: 모든 `gc()` 항목을 번들 성경(`GospelText.json`)과 대조 |

데이터 규모: **독서 참조 516개**(고유 시작점 353개), 고유복음 매핑 약 40건.

## 2. 출처 (Provenance)

1. **기반 데이터**: `ListenToGospel-Android`의 `Lectionary.kt` / `LiturgicalCalendar.kt` 를 Swift로 이식.
2. **절 범위(끝절)**: 로마 미사 독서 목록(Ordo Lectionum Missae, 1981 제2판) 표준 구절 범위.
   같은 시작점이라도 주일/평일/축일에 따라 범위가 다른 **36곳은 문맥별로 보정**
   (예: 성령 강림 요한 20,19-23 vs 부활 제2주일 20,19-31 / 성모 승천 루카 1,39-56 vs 대림4주일 다해 1,39-45).
3. **한국 관행 반영**: 주님 공현 = 1/2–1/8 사이 주일, 주님 승천 = 부활 제7주일(부활+42일),
   전례일 한국어 명칭 = 한국천주교주교회의(CBCK) 표기.
4. **주일 주기 기준점**: 전례주년 2026 = 가해 (`LiturgicalCalendar.sundayCycle`).

## 4. 알려진 한계 (Known limitations)

1. **평일 배열은 근사치 포함**: Android 원본의 평일 표 일부는 인접 독서로 근사되어 있음
   (예: 연중 21주간 목요일). 시작 장·절은 대체로 정확하나 1~2절 어긋나는 날이 있을 수 있음.
2. **장 경계를 넘는 독서**: 수난기(루카 22,14–23,56 등)는 해당 장의 끝 절까지로 한정
   (오디오·본문이 장 단위이므로).
3. **비연속 독서**: 요한 1,6-8+19-28 같은 발췌 독서는 연속 범위(6-28)로 표기.
4. **성인 기념일**: 의무 기념일의 선택 독서는 미반영(정규 평일 독서 우선). 대축일·축일만
   `properReading`으로 고유복음 처리.
5. **4복음서 범위**: 이 앱은 4복음서만 다루므로 복음 외 독서(제1·2독서, 화답송)는 없음.

## 5. 수정 시 절차 (Maintenance)

1. `Lectionary.swift` 를 수정한다 — 모든 참조는 `gc(복음서, 장, 시작절, 끝절)` 4-인자 형식.
2. **필수**: `python3 scripts/validate_lectionary.py` 실행 → `OK` 확인.
3. DEBUG 빌드로 앱을 한 번 실행 → 콘솔의 `LectionaryValidator: … readings validated` 확인
   (assert 실패 시 위반 날짜·참조가 메시지에 표시됨).
4. 실제 날짜 표본을 CBCK 매일미사(https://missa.cbck.or.kr)와 대조한다 — 최소한
   당일 + 다음 주일 + 가장 가까운 대축일.
5. 이 문서의 §3 검증 이력에 결과를 추가한다.
