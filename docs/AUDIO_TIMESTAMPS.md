# Audio Verse Timestamps — 오디오 장·절 표식 명세

`GospelForIpad/VerseTimestamps.swift` 와 이에 대응하는 `AudioFiles/` 의 89개 m4a는 이 앱의
**1급 데이터**입니다. 본문 하이라이트 동기화(가라오케), 오늘의 복음 시작-절 재생, 절 내비게이션이
모두 이 표식에서 나옵니다. 수정할 때는 반드시 이 문서의 검증 절차를 따르세요.

## 1. 구성

| 항목 | 내용 |
|------|------|
| 오디오 | 4복음서 89개 장, m4a(AAC). 장 단위 1파일. 출처: `ListenToGospel-Android` `audioPack` |
| `VerseTimestamps.swift` | `[장-1][절-1]` = 절 시작 시각(ms). 1절은 항상 0 |
| `scripts/validate_verse_timestamps.py` | 구조 검증(기본) + 오디오 대조 검증(`--audio`) |
| `LectionaryValidator.swift` (DEBUG) | 실행 시 표식 구조(0 시작·단조 증가·절 수 일치) 검사 |

데이터 규모: **절 표식 3,779개 / 89장** (마태 1,071 · 마르 678 · 루카 1,151 · 요한 879).

## 2. 검증 방법론 (2026-07-08, 2차 확정)

절 표식을 **실제 오디오 소리**와 **주교회의 성경(CCK) 본문** 양쪽에 대조·정렬했다.

**녹음 구조(실측으로 확인):**
- 모든 파일은 **책·장 이름 낭독(인트로)** 으로 시작한다(예: "마태오복음서 1장" + 긴 휴지,
  1장은 소제목도 이어 낭독). **1절은 0초가 아니라 인트로 뒤(중앙값 6.8초, 5.0~15.7초)에 시작**한다.
- **장 중간에도 소제목(pericope 제목)이 낭독**된다. 위치는 공동번역 원문의 `[제목]` 마커에서
  추출한 **488개** pericope 시작 절을 사용.

**정렬 파이프라인:**
1. m4a → 16 kHz 모노 PCM → 50 ms 프레임 RMS → 적응 임계값으로 ≥300 ms 휴지 검출.
2. **인트로 검출**: "누적 발화 ≤6.5초 & 처음 16초 이내"에서 **마지막 ≥1.8초 휴지** 직후의
   발화 시작점 = 1절 시작. (실측 대조: 마태1=6.8s, 요한1=10.0s 정확 일치)
3. **순차 드리프트-보정 스냅**: k절 예측 = (k-1)절 확정 위치 + (k-1)절 글자수×속도
   (+ 소제목 절이면 제목 글자수×속도 + 3초 휴지 보정). 예측 주변(±5.5~6.5초)에서
   휴지 길이·발화 길이 가중 비용 최소의 발화 시작점으로 확정.
4. 결과: **3,690개 표식(2절 이후 전부) 100% 정착, 미정착 0, 예측 잔차 중앙값 0.45초.**

**하이라이트 동작**: 1절 시작 전(제목 낭독 중)에는 `currentVerse`가 nil을 반환하여
아무 절도 강조하지 않는다.

## 3. 검증 이력

- **2026-07-08 (2차)** — 사용자 보고(제목 낭독 구간 불일치)로 녹음 구조 재분석:
  인트로·장중 소제목 낭독을 모델링해 **전 표식 재정렬**. 1절 실측 일치(마태1 6.8s·요한1 10.0s),
  3,690개 전부 정착·잔차 중앙값 0.45s. `validate_verse_timestamps.py --audio` OK.
- **2026-07-08 (1차)** — 원본(글자수 비례 추정) 대조: 구조 오류 0, 절 수 불일치 0.
  ※ 1차는 인트로를 몰라 전체가 한 박자 밀렸음 — 2차로 대체됨.

## 4. 알려진 한계

1. onset 검출은 휴지 뒤 첫 발화를 절 시작으로 본다 — 낭독자가 절 경계에서 쉬지 않은 경우
   문장 경계로 정렬될 수 있다(정렬 편차 ≤ 4.2초라 영향 미미).
2. 절 경계와 문장 경계가 겹치는 짧은 절 연속 구간에서는 ±1 휴지 오차 가능성.
3. 1절 표식은 인트로 낭독 종료 지점이다(0이 아님). 1절부터 재생하면 인트로를 건너뛴다.
4. 표식은 주교회의 성경(CCK) 절 구분 기준이다. 타 번역본(200주년·공동번역·NAB)의 절 구분이
   다른 소수 구절(마르 7,16 등)은 CCK 기준으로 표시된다.

## 5. 수정 시 절차 (Maintenance)

1. 오디오 파일을 교체/추가하면 반드시 표식을 재생성한다(방법론 §2, 또는 비례 추정 후 정렬).
2. **필수**: `python3 scripts/validate_verse_timestamps.py` → `OK` 확인.
3. 오디오까지 대조하려면(권장): `pip install av numpy` 후
   `python3 scripts/validate_verse_timestamps.py --audio` → `OK` 확인.
4. DEBUG 빌드 실행 → 콘솔에서 검증 로그 확인.
5. 이 문서의 §3 검증 이력에 결과를 추가한다.
